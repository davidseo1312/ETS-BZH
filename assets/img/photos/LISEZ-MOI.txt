EMPLACEMENTS PHOTO DU SITE ETS-BZH
==================================

Déposez vos photos dans CE dossier, en respectant EXACTEMENT les noms de
fichiers ci-dessous. Aucune modification de code n'est nécessaire : dès que le
fichier existe, la photo remplace le cadre d'attente affiché sur le site.

Format conseillé : JPEG, 1200 x 900 px (galeries) ou 1200 x 800 px (photos
larges), poids < 250 Ko. Le cadrage est automatique (recadrage centré).

CHANGER UNE LÉGENDE OU UN TEXTE ALTERNATIF
------------------------------------------
Les légendes et descriptions se modifient dans tools/data.py (clés « photos »,
« photo_equipe », PHOTOS_ACCUEIL, PHOTO_EQUIPE, PHOTO_CONTACT), puis relancez :
    python3 tools/build.py

MASQUER LES EMPLACEMENTS NON REMPLIS
------------------------------------
Dans assets/css/style.css, décommentez la règle :
    .photo--vide { display: none; }

IMPORTANT : n'utilisez que des photos dont vous détenez les droits (vos propres
chantiers de préférence). Évitez les banques d'images génériques : elles nuisent
à la crédibilité et peuvent poser un problème juridique si elles sont présentées
comme vos réalisations.
